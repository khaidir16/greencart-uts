# GreenCart — Live Demo Script

Target durasi: 5–7 menit.

1. Buka beranda dan jelaskan fallback/scene tanaman 3D.
2. Buka katalog sebagai Guest; demonstrasikan pencarian, filter, dan sort.
3. Login `customer / Customer123!`.
4. Buka detail produk, pilih jumlah, dan tambahkan ke cart.
5. Ubah quantity pada cart dan lanjut checkout.
6. Isi telepon serta alamat, lalu konfirmasi.
7. Catat nomor order dan tunjukkan status awal DRAFT.
8. Logout/masuk sebagai `admin / Admin123!`.
9. Buka dashboard dan daftar pesanan.
10. Temukan nomor order, buka detail, dan ubah menjadi CONFIRMED.
11. Buka `/api/docs` untuk menunjukkan kontrak OpenAPI.
12. Tampilkan evidence: 75 API test, 9 Web test, 15 BDD scenario, dan 9 Cypress E2E.

Jika jaringan/deployment bermasalah, gunakan aplikasi lokal dan evidence video Cypress sebagai
fallback demo.
